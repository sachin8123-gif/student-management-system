# Student Management System

A console-based Java application to manage student records.

## Features
- Add, view, search, update and delete students
- Automatic grade calculation
- Topper finder
- Data saved in a text file (file handling)

## Concepts Used
OOP (classes, objects, encapsulation), ArrayList, Exception Handling, File I/O

## How to Run
1. Download Main.java
2. Compile: javac Main.java
3. Run: java Main
